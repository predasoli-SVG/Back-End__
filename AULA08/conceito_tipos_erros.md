2xx -SUCESSO (tudo certo)
    200 - ok - requisito funcionou
    201 - criado - post funcioonou

3xx rediricionamneto - mudou de lugar
    301 - mudou permanente

4xx - ERRO DO CLIENTE - voce errou
    400 - requisitação errada
    401 - nao autorizada (sem login)
    403 - proibido (login sem permissao)
    404 - não encontrado

5xx - erro do servidor (eles erraram)
    500 - erro interno no servidor
    503 - servidor indisponivel

    CENARIO VC PEDE UMA PIZZA 🍕

    200 = aqui esta a sua pizza
    404 = nao temos essa pizza
    500 = o forno queimou ou quebrou
    401 = só entregamos para clientes 🔒
    429 = muitos pedidos, aguarde ⏳
